# Google Play Release Assets Checklist

Date: 2026-05-22

Reference: https://support.google.com/googleplay/android-developer/answer/9866151

## Required Store Assets

- App name: SWIMVPN
- Short description RU
- Full description RU
- Short description FR if localized listing is used
- Full description FR if localized listing is used
- App icon
- Feature graphic
- Phone screenshots
- Privacy policy URL
- Contact email
- App category
- Data Safety form
- VpnService declaration

## Recommended Screenshot Coverage

- Home connection screen
- Servers screen with Agent guidance
- Subscription screen
- Import config flow
- Account / settings screen
- Trial or pre-release access messaging if approved for public listing

## Asset Quality Rules

- Use the same SWIMVPN shark mark and dark/lavender visual grammar as the Android app.
- Avoid showing raw supplier configs, hostnames, UUIDs, IPs, or sensitive node metadata.
- Avoid overpromising autonomous AI behavior; show Agent as guidance/indices.
- Avoid mentioning unsupported protocol formats unless verified in parser/runtime.

## Open Items

- Produce final Play Store screenshots from release-candidate APK.
- Confirm final localized screenshots for RU and FR.
- Confirm whether pre-release/trial language is still valid at submission time.
