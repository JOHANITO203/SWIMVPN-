# Google Play Store Listing Draft - RU

## Short Description

SWIMVPN - VPN Android с trial, покупкой доступа и импортом конфигов.

## Full Description

SWIMVPN - это Android VPN для тех, кто хочет быстро подключиться, купить готовый VPN-доступ внутри приложения или использовать собственные конфиги бесплатно.

Приложение помогает начать без сложной настройки: установите APK, активируйте текущий trial, выберите доступный сервер или импортируйте свою VPN-конфигурацию.

## Why SWIMVPN

- Готовый VPN-доступ можно купить прямо в приложении.
- Можно использовать собственные конфиги, если у вас уже есть доступ.
- Поддерживается импорт популярных форматов из экосистемы Xray/V2Ray: VLESS, VLESS Reality, VMess, Trojan, Shadowsocks, JSON Xray и JSON V2Ray, если они поддерживаются текущим runtime.
- Agent показывает полезные индексы и помогает понять, какие узлы выглядят лучше в реальном времени.
- Trial доступен в pre-release период, пока команда готовит финальный релиз.

## Payments

SWIMVPN поддерживает оплату через SwimPay и Crypto. Эти способы оплаты встроены в продуктовый поток и будут уточняться по мере подготовки релиза.

## Important Notes

- SWIMVPN использует Android VPN-сервис для создания защищенного VPN-подключения.
- Приложение не предназначено для рекламы, отслеживания или продажи пользовательского трафика.
- Доступность trial и отдельных способов оплаты может зависеть от региона, версии приложения и текущей кампании.
