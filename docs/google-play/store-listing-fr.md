# Google Play Store Listing Draft - FR

## Description Courte

SWIMVPN - VPN Android avec trial, achat in-app et import de configs personnelles.

## Description Longue

SWIMVPN est un VPN Android pensé pour une prise en main simple : acheter un accès VPN directement dans l'application, tester le trial actuel, ou utiliser gratuitement une configuration VPN que vous possédez déjà.

L'app vise un usage clair et rapide : installez l'APK, activez le trial si disponible, sélectionnez un serveur, ou importez votre configuration.

## Pourquoi SWIMVPN

- Achat d'accès VPN intégré dans l'application.
- Utilisation gratuite possible avec vos propres configurations.
- Import orienté écosystème Xray/V2Ray : VLESS, VLESS Reality, VMess, Trojan, Shadowsocks, JSON Xray et JSON V2Ray lorsque le runtime courant les prend en charge.
- Agent avec indices en temps réel pour aider à repérer les meilleurs noeuds disponibles.
- Version pre-release disponible avant la release Play Store, avec trial actuel.

## Paiements

SWIMVPN présente SwimPay et Crypto comme moyens de paiement supportés dans le parcours produit. Les détails définitifs doivent être validés avant publication officielle.

## Notes Importantes

- SWIMVPN utilise le service VPN Android pour créer une connexion VPN.
- L'application n'est pas conçue pour la publicité, le tracking ou la revente du trafic utilisateur.
- La disponibilité du trial et des moyens de paiement peut dépendre de la région, de la version et de la campagne active.

## Intentions SEO / Store

VPN Android, Xray VPN, V2Ray VPN, VLESS, Trojan VPN, Shadowsocks, import config VPN, trial VPN, acheter accès VPN, SWIMVPN.
